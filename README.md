# 📚 Локальная Флибуста (Flibusta Local Mirror)

Удобная домашняя библиотека в Docker с современным интерфейсом, встроенной читалкой и поддержкой OPDS для электронных книг. 

Все ваши книги всегда под рукой на домашнем сервере, ПК или NAS (Synology, TrueNAS, OpenMediaVault, Unraid) — работают быстро, автономно и даже без доступа в интернет.

---

## 🌟 Обзор сервиса: что умеет библиотека

### 1. 📖 Каталог книг и витрина
* **Светлая и тёмная темы**: комфортно пользоваться и днём, и ночью (переключатель ☀️ / 🌙 в шапке сайта, сохраняет ваш выбор).
* **Два режима отображения**:
  * **3D-книжная полка (Сетка)**: карточки книг с эффектом книжного корешка и обложками, выстроенные ровными рядами.
  * **Список**: компактный режим с аннотациями и подробными метаданными для быстрого просмотра.
  * Переключение между сеткой и списком происходит мгновенно в один клик.
* **Умные обложки (Fallback Covers)**: если у книги нет картинки обложки, система сама рисует красивую типографическую обложку с градиентом и названием — никаких серых «битых» картинок.

### 2. 🔍 Поиск и фильтрация
* **Быстрый поиск**: ищет по названиям, авторам, сериям и тексту аннотаций.
* **Быстрые фильтры**: в один клик можно отфильтровать только книги на русском языке или только книги в формате FB2.
* **Каталоги по разделам**: отдельные удобные страницы для **Жанров**, **Авторов** и книжных **Серий** с алфавитным указателем.

### 3. ☕ Встроенная читалка в браузере (Zen Reader)
Не обязательно скачивать файл — любую книгу можно читать прямо в браузере с компьютера, планшета или смартфона:
* **Настройка шрифта**: кнопки увеличения и уменьшения размера текста (**A-** / **A+**), выбор шрифта с засечками (книжный) или без засечек (экранный).
* **4 цветовые палитры для комфорта глаз**:
  * 📄 **Бумага** — классический мягкий белый.
  * 📜 **Сепия** — тёплый бумажный оттенок, снижающий нагрузку на зрение.
  * 🌙 **Ночь** — контрастная тёмная тема для чтения в темноте.
  * 🖤 **OLED** — глубокий чёрный цвет для экономии батареи мобильных экранов.
* **Полноэкранный режим** и **индикатор прочитанного** сверху страницы.
* Автоматическое запоминание места чтения для формата FB2.

### 4. 📱 OPDS-каталог для мобильных читалок и ридеров
Библиотека раздаёт встроенный OPDS-каталог по адресу `http://<IP-вашего-сервера>:27100/opds/`. 
Вы можете подключить её напрямую к вашей любимой читалке на телефоне или ридере:
* **Android / iOS**: FBReader, Moon+ Reader, ReadEra, Librera.
* **Электронные книги**: PocketBook, Onyx Boox, KOReader (на Kindle/Kobo).
Книги скачиваются сразу в читалку в один клик.

### 5. 🔖 «Моя полка» (Избранное)
* Нажмите на сердечко у любой книги, автора или цикла, чтобы отложить их в избранное.
* Раздел «Полка» визуально разделяет отложенных авторов, серии и книги.
* Поддерживается смена читателей (профили полок для членов семьи).

### 6. ⚙️ Раздел «Сервис»
Удобная панель управления прямо в браузере:
* Наглядная статистика: сколько в базе книг, авторов, жанров и серий.
* Кнопка **«Обновить базу»**: скачивает и обновляет каталог в один клик без ввода команд в терминале.
* Кнопка **«Сканирование ZIP»**: проверяет папку с файлами книг и связывает новые архивы с базой данных.
* Кнопка **«Очистить кэш»**: удаляет временные файлы и старые картинки.

## 🚀 Простая установка (Шаг за шагом)

Для работы потребуется только установленный **Docker** и **Docker Compose**.

### Шаг 1: Скачайте проект
Откройте терминал на сервере или компьютере и выполните:
```bash
git clone https://github.com/scanek/flibusta.git
cd flibusta
```

### Шаг 2: Настройте путь к книгам
Скопируйте пример настроек в рабочий файл:
```bash
cp .env.example .env
```
Откройте файл `.env` в любом текстовом редакторе (например, `nano .env`) и укажите путь к папке, где у вас лежат (или будут лежать) архивы книг:
```env
BOOKS_DIR=/путь/к/папке/с/книгами
WEB_PORT=27100
```
> *Примечание:* Если папка пустая — ничего страшного, её можно наполнить позже.

### Шаг 3: Выдайте права на папки (Обязательно для Linux / NAS)
Внутри Docker веб-сервер работает под пользователем `www-data` (UID 82). Чтобы он мог сохранять обложки, создавать логи (`sync.log`) и запускать скрипты синхронизации, дайте права на запись:
```bash
chmod -R 777 cache FlibustaSQL
chmod +x *.sh application/tools/*
```
> 💡 *Если вы редактировали файлы на Windows или клонировали с CRLF-окончаниями, исправьте их в Linux:*
> `sed -i 's/\r$//' *.sh application/tools/*.sh`

### Шаг 4: Запустите контейнеры
Выполните команду запуска:
```bash
docker compose up -d
```
Docker запустит веб-сервер, PHP и базу данных PostgreSQL. 

Теперь библиотека доступна в браузере по адресу:
👉 `http://<IP-адрес-вашего-сервера>:27100/`

## 🔒 Важно: Права доступа на папки (почему это нужно?)

В операционных системах Linux и на NAS (Synology, TrueNAS, OMV) безопасность устроена так, что контейнеры Docker запускаются с ограниченными правами системного пользователя `www-data` (UID `82` в Alpine Linux).

* **Если папки созданы от `root` без прав записи**:
  * При нажатии «Обновить базу» лог не сможет создаться, и вы увидите: `tail: cannot open 'FlibustaSQL/sync.log': No such file or directory`.
  * Веб-читалка и сервер не смогут распаковать и сохранить обложки в папку `cache/covers`.
  * Скрипты синхронизации завершатся с ошибкой `Permission denied`.

* **Универсальное решение в одну строку**:
  ```bash
  chmod -R 777 cache FlibustaSQL
  chmod +x *.sh application/tools/*
  ```
  *(или назначить владельца: `chown -R 82:82 cache FlibustaSQL`)*.

## 📥 Первоначальное наполнение книгами и базой

Чтобы на сайте появились книги, нужно загрузить две вещи: **каталог (базу данных)** и **сами файлы книг**.

### 1. Загрузка базы данных (каталога)
Выберите **любой один** удобный способ:
* **Через браузер (самый простой)**:
  Откройте в меню раздел **«Сервис»** (`http://<IP>:27100/service/`) и нажмите синюю кнопку **«Обновить базу»**. Сервер сам скачает актуальный дамп, конвертирует его и загрузит в PostgreSQL.
* **Через терминал**:
  ```bash
  docker compose exec -d php-fpm /application/tools/docker_sync_sql.sh
  ```
  *(Следить за ходом загрузки можно командой: `tail -f FlibustaSQL/sync.log`)*.

### 2. Размещение файлов книг
* Положите архивы с книгами (`f.fb2.000001-010000.zip`, `f.fb2.010001-020000.zip` и т.д.) в ту папку, которую вы указали в `BOOKS_DIR` в файле `.env`.
* Если у вас ещё нет архивов, докачать свежие ежедневные выпуски можно командой:
  ```bash
  ./update_daily.sh -d
  ```

### 3. Индексация (связка базы с файлами)
Когда база загружена и архивы лежат в папке, откройте в браузере раздел **«Сервис»** и нажмите **«Сканирование ZIP»**. Система просканирует файлы и свяжет их с карточками книг.

## 🔄 Как обновлять сервис и книги

### 1. Обновление кода самого сервиса (новые функции, дизайн, исправления)
Когда выходят обновления интерфейса, подтянуть их очень просто:
```bash
cd /путь/к/flibusta

# 1. Сохраняем локальные настройки (.env) и стягиваем свежий код из GitHub
git stash
git pull origin main
git stash pop

# 2. Обновляем права на скрипты и папки
chmod +x application/tools/* *.sh
chmod -R 777 cache FlibustaSQL

# 3. Перезапускаем контейнеры
docker compose restart
```
*Все ваши настройки, база данных и скачанные книги остаются в полной сохранности!*

---

### 2. Обновление базы книг (раз в месяц или по желанию)
Серверы Флибусты регулярно выпускают свежие списки вышедших книг.

* **Вручную когда захотите**: зайдите в раздел **«Сервис»** и нажмите **«Обновить базу»**.
* **Автоматически раз в месяц (по расписанию через Cron)**:
  Чтобы сервер сам обновлял каталог, например, 1-го числа каждого месяца в 03:00 ночи:
  1. Откройте планировщик задач:
     ```bash
     crontab -e
     ```
  2. Добавьте в конец файла строку (замените путь на ваш каталог):
     ```cron
     0 3 1 * * cd /путь/к/flibusta && docker compose exec -T php-fpm /application/tools/docker_sync_sql.sh >> FlibustaSQL/cron.log 2>&1
     ```

## 📱 Как подключить читалку на телефоне или ридере (OPDS)

1. Откройте вашу читалку (Moon+ Reader, FBReader, ReadEra, KOReader).
2. Перейдите в меню: **Сетевые библиотеки** (или **Каталоги OPDS**) ➔ **Добавить каталог**.
3. В поле «Название» укажите: `Моя Флибуста`.
4. В поле «Адрес / URL» введите:
   ```text
   http://<IP-вашего-сервера>:27100/opds/
   ```
5. Нажмите «Сохранить». Теперь вся ваша домашняя библиотека доступна прямо внутри читалки с удобным поиском и скачиванием в один клик.
